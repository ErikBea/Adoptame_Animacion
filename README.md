# Ideas de diseño
He optado por seguir el diseño original de la plataforma Adóptame con unos pequeños cambio mejorados mediante animaciones SVG y CSS.
La plataforma cuenta con dos secciones definidas, el título de Adoptame con un texto para incentivar a la adopción y las mascotas que se adoptan, gatos y perros, seguidos de un botón de conocer más.
Las secciones principales se encuentran integradas en una tarjeta que centran la atención en los componentes.
Una gran mejora de logo para Adóptame es el hecho de añadir la pata de un animal en el título aprovechando los SVG y animaciones.
# SVG
Para el proyecto se han creado 3 SVGs uno para el perro, otro para el gato y por último uno para la huella.
Los SVGs se han hecho con la plataforma Figma, enlace al tablero: https://www.figma.com/design/9n7rMx95b6mUHk5otol5vm/SVG?node-id=0-1&t=Wv4om2lOy5llecE5-1
# Animaciones
Se han diseñado distintas animaciones para cada SVG, en el caso de la huella, se va dibujando cuando se carga la página.
Para el perro se ha creado una animación para mover la cola de izquierda a derecha. 
En cuanto al gato este contiene dos animaciones, una para parpadear y otra en la que mueve los bigotes.
El botón de "Conocer más" también está animado de tal forma que cuando se pasa el ratón por encima se hace un zoom para más tarde volver a su lugar.
